# 🎬 천만 영화 분석기 (10M Movie Analyzer)

위키백과 **[대한민국의 영화 흥행 기록](https://ko.wikipedia.org/wiki/대한민국의_영화_흥행_기록)** 문서에서 한국 작품 흥행 순위 데이터를 실시간으로 스크래핑하고, 이를 정제하여 시각화하는 **Streamlit 기반 데이터 분석 웹 애플리케이션**입니다.

---

## ✨ 주요 기능

1. **실시간 웹 스크래핑 및 예외 처리**
   - `requests`와 `BeautifulSoup4`를 이용해 위키백과 문서에서 `'관객수'`와 `'감독'` 컬럼이 포함된 흥행 순위 표(`wikitable`)를 자동으로 탐색합니다.
   - 네트워크 연결 오류, 요청 시간 초과(Timeout), HTTP 상태 코드 오류를 감지해 사용자에게 안내합니다.

2. **데이터 자동 정제 (Data Cleaning)**
   - 위키백과 특유의 각주 번호(`[1]`, `[2]` 등)와 영화 제목의 겹낫표(`《`, `》`)를 제거합니다.
   - 관객수 문자열에서 숫자만 추출해 정수형으로 변환하고, 개봉일에서 `개봉연도`와 `개봉월`을 파생 변수로 생성합니다.

3. **핵심 지표(KPI) 및 데이터 테이블 제공**
   - 총 천만 영화 편수, 역대 1위 작품 및 관객수, 가장 최근 개봉한 천만 영화 정보를 상단 대시보드에 요약합니다.
   - 정제된 전체 흥행 순위 데이터를 인터랙티브 표로 확인할 수 있습니다.

4. **다양한 시각화 차트 및 심화 분석**
   - **관객수 상위 10편**: 가로 막대 차트(Horizontal Bar Chart)로 순위 비교
   - **개봉 연도별 추이**: 연도별 천만 영화 탄생 편수 시각화
   - **개봉 월별 분석 (추가 기능)**: 월별 개봉 편수 차트 및 여름·겨울방학 시즌(1·2·7·8·12월) 개봉 비율 계산
   - **천만 감독 분석 (추가 기능)**: 천만 영화를 2편 이상 연출한 감독과 해당 작품 목록 정리

---

## 🛠️ 기술 스택

- **Language**: Python 3.x
- **Web Framework**: Streamlit
- **Web Scraping**: Requests, BeautifulSoup4
- **Data Processing**: Pandas, Regular Expressions (`re`)

## 🚀 설치 및 실행 방법

### 1. 필수 라이브러리 설치
터미널에서 아래 명령어를 입력해 필요한 패키지를 설치합니다.

```bash
pip install streamlit requests pandas beautifulsoup4
```

### 2. 애플리케이션 실행
`app_8_2_movie_plus.py` 파일이 있는 디렉터리에서 다음 명령어를 실행합니다.

```bash
streamlit run app_8_2_movie_plus.py
```

실행 후 자동으로 열리는 웹 브라우저(기본 주소: `http://localhost:8501`)에서 **[흥행 순위 가져오기]** 버튼을 클릭하면 데이터를 불러와 분석 결과를 확인할 수 있습니다.

## 📂 코드 구조

| 함수명 | 설명 |
| :--- | :--- |
| `fetch_html(url, timeout=10)` | 지정된 URL의 HTML 문서를 가져오고, 발생 가능한 네트워크 오류를 처리합니다. |
| `find_ranking_table(html)` | HTML 내 `wikitable` 중 `'관객수'`와 `'감독'` 헤더가 모두 포함된 첫 번째 표를 찾습니다. |
| `table_to_dataframe(table)` | 각주(`<sup>`)를 제거하고 표의 행과 열을 읽어 Pandas DataFrame으로 변환합니다. |
| `clean_movies(df)` | 제목 기호 제거, 관객수 숫자 변환, 개봉연도/개봉월 추출 등 분석용으로 데이터를 정제합니다. |
| `show_release_month(df)` | 개봉 월별 편수를 막대 차트로 출력하고 방학 시즌 개봉 비율을 계산합니다. |
| `show_directors(df)` | 천만 영화를 2편 이상 연출한 감독과 대표작 목록을 표로 출력합니다. |
